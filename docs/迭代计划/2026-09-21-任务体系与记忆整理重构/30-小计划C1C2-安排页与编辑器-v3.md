## C.2 段与数据源（v3，与总体方案 v3 §3 对齐）
```
应做四段（计入 dueCount）：每日·固定 / 每日·留白 / 临时·今天 / 杂项待办（来自记录，可隐藏，可勾选/删除/转为任务）
补充三段（不计入）：已过期(临时) / 待补录(近30天漏做) / 待回填(近7天留白，折叠)
呈现分组：今日已完成（折叠）      生命周期列表：已结束（archived，折叠，只在"管理任务"里可见）
数据卡片区：进行中的计划 / 目标
顶部：完成率环 doneCount/dueCount（当天恒定分母）+ 段头 "1/3" 用该段 planned 的 DONE 数
```
段头计数、环、`issues` 尾部提示（「N 条任务配置异常」可展开）全部取 `DayPlanResult` 字段，UI 不做任何 size/filter 计算。
